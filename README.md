# Proyecto Final - Estructura de Datos

## Tema
Encuentro de vuelos baratos a partir de una base de datos ficticia mediante un grafo dirigido y ponderado.

## Requisitos
- Python 3.10 o superior.

## Ejecución
```bash
python app_vuelos.py
```

## Pruebas
```bash
python pruebas.py
```

## Archivos
- `app_vuelos.py`: implementación del grafo, reportería y Dijkstra.
- `vuelos.txt`: base de datos ficticia de rutas y precios.
- `pruebas.py`: cinco pruebas funcionales automatizadas.
- `salida_demo.txt`: evidencia textual de ejecución.
- `captura_ejecucion.png`: evidencia gráfica de ejecución.
- `grafo_vuelos.png`: visualización del grafo utilizada en el informe.
